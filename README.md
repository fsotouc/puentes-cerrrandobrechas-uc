# Puentes — demo

Plataforma que conecta liceos públicos y subvencionados con organizaciones de la sociedad civil que buscan estudiantes voluntarios.
Proyecto universitario · Cerrando Brechas Educativas · EDU222B · Grupo 5.

## Ver la demo

`index.html` es un archivo autocontenido: ábrelo directo en el navegador o publícalo con GitHub Pages.

### Publicar con GitHub Pages
1. Crea un repositorio nuevo en github.com (ej. `puentes`), público.
2. Sube todos los archivos de esta carpeta (botón **Add file → Upload files**).
3. Ve a **Settings → Pages**, en *Branch* elige `main` y carpeta `/ (root)`, y guarda.
4. En 1–2 minutos queda en `https://TU-USUARIO.github.io/puentes/`.

## Archivos fuente
- `index.html` — demo navegable (8 pantallas, escritorio y móvil)
- `*.dc.html` — pantallas individuales (requieren servidor local: `npx serve .`)
- `support.js`, `image-slot.js` — runtime de las pantallas
